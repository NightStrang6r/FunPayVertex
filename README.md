## :robot: **Возможности**

### :shopping_cart: **FunPay**

- Автовыдача товаров.
- Автоподнятие лотов.
- Автоответ на заготовленные команды.
- Автовосстановление лотов после продажи.
- Автодеактивация лотов, если товары закончились.
- Вечный онлайн.
- Уведомления в Telegram.
- Полноценная ПУ в Telegram.

### :left_speech_bubble: **Уведомления и ПУ в Telegram**

- Возможность установки нескольких чатов для уведомлений.
- Уведомления о поднятии лотов, новых заказах, выдаче товара и новых сообщениях.
- Возможность отвечать на сообщения прямо из Telegram.
- Возможность полностью настраивать автовыдачу / автоответчик и все остальные модули.
- Возможность добавлять автовыдачу для лотов, получая лоты прямо с FunPay.
- Управление списком авторизованных пользователей ПУ.

### :gear: **Дополнительные возможности**

- Использование переменных в тексте для автоответа / автовыдачи.
- Система плагинов — кастомизация функционала без редактирования исходного кода.
- Три языка интерфейса: русский, английский, украинский.
- Поддержка прокси для FunPay и для Telegram.
- Создание и восстановление резервных копий конфигов, хранилища и плагинов.

## :arrow_down: Установка

Требуется **Python 3.11** или новее.

### :large_blue_diamond: Windows

1. Скачайте и установите [Python](https://www.python.org/downloads/).
   1. При установке поставьте галочку у `Add python.exe to PATH` на первом экране установки.
2. Скачайте FunPay Vertex и перенесите папку в нужное вам место.
3. Запустите `Setup.bat` и дождитесь окончания установки зависимостей.
4. Запустите `Start.bat`. При первом запуске откроется мастер первичной настройки.

### :hotsprings: Linux (Ubuntu)

Выполните команду и следуйте инструкциям установщика:

```bash
wget https://raw.githubusercontent.com/NightStrang6r/FunPayVertex/main/install-fpv.sh -nc && bash install-fpv.sh
```

Скрипт установит всё необходимое и добавит бота как systemd-службу.

### :whale: Docker

**Перед запуском в Docker необходимо уже иметь готовые конфиги** — образ не может запустить мастер первичной настройки.

```bash
docker-compose up -d --build
```

Проверить работоспособность: `docker-compose logs -f`

## :hammer_and_wrench: Настройка конфигов

1. Все конфиги находятся в папке `configs`.
2. Все инструкции по настройке находятся внутри самих конфигов.
3. Основной конфиг со всеми переключателями: `configs/_main.cfg`
4. Конфиг автоответчика: `configs/auto_response.cfg`
5. Конфиг автовыдачи: `configs/auto_delivery.cfg`

Конфиги должны быть в кодировке **UTF-8** с переводами строк **LF**.

## :electric_plug: Плагины

Плагины устанавливаются через Telegram ПУ: `/menu` → `🧩 Плагины` → `➕ Добавить плагин`.

> [!WARNING]
> **Не устанавливайте плагины из недоверенных источников.** Плагин — это произвольный Python-код, который выполняется с правами бота. Через систему плагинов злоумышленник может получить полный доступ к вашему устройству и аккаунту FunPay.

## :floppy_disk: Резервные копии

- `/create_backup` — создать резервную копию (конфиги, хранилище, плагины) и получить её файлом.
- `/get_backup` — получить последнюю созданную копию.
- `/upload_backup` — восстановить из копии.

Автоматического обновления из интернета в этой сборке нет: бот не скачивает и не устанавливает код самостоятельно. Обновление выполняется вручную.
